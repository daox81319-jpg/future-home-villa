# 风水宝地中式别墅：建筑设计方案与首批效果图

<callout emoji="🏮">
**主要判断**
- **总图**：采用中轴礼序加四象围合，形成藏风聚气的院落。
- **风水**：前照后靠、左高右稳，水景收气，假山定势。
- **建模**：优先拆成门楼、主楼、连廊、园林、室内五组资产。
- **交互**：Godot 以日夜漫游和热点讲解为首版目标。
</callout>

## 一、设计定位

本方案为一座中型中式别墅的概念设计，目标是把传统院落的礼序、风水中的四象关系，以及现代居住的舒适尺度放在同一个空间骨架里。建筑采用青瓦、白墙、深色木构、石材铺地与格扇门窗，外部重院落层次，内部重轴线、光线与木作比例。

整体建议按约 42m × 34m 的矩形基地推演，建筑面积约 650–780㎡，庭院及景观面积约 750–900㎡。尺度可随真实地块调整，核心关系不变：前方留明堂，后方设靠山，左侧用绿植与长廊抬势，右侧用石景与厢房收稳。

---

## 二、风水总图

院落以南向入门为默认设定：大门、影壁、前院水景、主楼大堂形成一条可见但不直冲的中轴线。动线进入后先被照壁缓冲，再绕水而行，气流不会直穿主厅；后院用假山、松柏和高院墙收束视线，形成“前有照、后有靠”的稳定感。

| 方位 | 风水角色 | 设计做法 | 建模重点 |
|-|-|-|-|
| 前方 | 明堂 / 照 | 入口内侧设影壁，前院布半月形荷花池，水面保持低位开阔。 | 门楼、照壁、月牙池、石板路。 |
| 后方 | 玄武 / 靠 | 后院设假山、叠水、高院墙和常绿乔木，形成视觉与心理靠背。 | 假山组、院墙、松柏、瀑布水材质。 |
| 左侧 | 青龙 | 左侧抬高绿量，布连续廊道与竹林，使左侧更有生长感。 | 长廊、竹丛、花窗、廊灯。 |
| 右侧 | 白虎 | 右侧采用低矮厢房、石景和修剪灌木，体量安静，避免压过主楼。 | 厢房、太湖石、矮墙、碎石铺装。 |
| 中央 | 聚气 | 主楼居中略后退，客厅面向水院，天井与格扇门引入柔光。 | 主厅、露台、木梁柱、格扇门。 |

## 三、空间组织与尺寸参考

平面采用“一进院 + 主楼 + 两侧院 + 后花园”的结构。访客动线从门楼进入，经照壁转折到前院，再进入大堂；家庭动线可从侧门进入厨房、餐厅与后勤区，避免穿越主厅。室内空间以主厅为核心，书房茶室贴近侧院，佛堂或冥想室放在更安静的后侧。

| 区域 | 参考尺寸 | 功能与气质 | 关键元素 |
|-|-|-|-|
| 门楼与影壁 | 宽 6–8m | 完成入户转折，避免大门直冲主厅。 | 木门、铜钉、照壁浮雕、石狮。 |
| 前院水景 | 约 12m × 10m | 作为明堂与聚水区，水面不宜过深，岸线柔和。 | 荷花池、汀步、锦鲤、石桥。 |
| 主楼大堂 | 约 8m × 9m | 会客、家庭核心活动，需有中轴对称与开阔视线。 | 梁柱、天井、山水画、主沙发。 |
| 主卧套间 | 约 6m × 7m | 朝向后院或侧庭，强调安静、低眩光与收纳完整。 | 木格屏风、衣帽间、内卫。 |
| 书房茶室 | 约 5m × 6m | 靠左侧竹院，适合阅读、会客、品茶和静坐。 | 书案、茶台、博古架、竹影窗。 |
| 餐厅 | 约 5m × 5m | 连接厨房和侧院，可做家庭宴请。 | 圆桌、吊灯、屏风、边柜。 |
| 厨房 | 约 4m × 5m | 设在右后侧，便于后勤出入与排烟。 | 中厨、西厨岛台、储藏间。 |
| 佛堂 / 冥想室 | 约 4m × 4m | 放在后侧安静处，避免临近厨房和强噪声区。 | 佛龛、蒲团、香案、柔光壁龛。 |
| 后院假山 | 约 14m × 8m | 作为靠山与私密景观，水声宜轻，植物以常绿为主。 | 假山、叠水、松柏、月洞门。 |

## 四、建筑与室内美学

外立面以青瓦白墙为底，屋顶采用双坡或歇山式轮廓，檐口微翘，避免夸张宫殿化。梁柱、门窗、栏杆统一用深胡桃木或深栗色木材，石材地面选青灰色板岩或仿古花岗岩，降低反光，让水景、竹影和木作成为画面主体。

室内不做过度雕花。大堂以木梁、格扇门、山水画和低饱和软装建立秩序；主卧弱化仪式感，转向舒适和安静；书房茶室保留留白，让茶台、书案和窗外竹影成为焦点；餐厅以圆桌和屏风延续团聚意味；佛堂或冥想室使用低照度暖光，材料以木、石、棉麻为主。

## 八、Godot 交互场景搭建方案

Godot 首版建议做“慢速漫游 + 热点讲解 + 日夜光照切换”。别墅项目的交互价值不在复杂玩法，而在让用户理解院落秩序、风水节点和室内外关系。

| 模块 | 实现方案 | 配置建议 |
|-|-|-|
| 场景结构 | Root 下分 Exterior、Interior、Landscape、Lighting、UI、Navigation 六组节点。 | 每组独立 Collection 导入，便于替换 LOD。 |
| 漫游相机 | 使用 CharacterBody3D 加 Camera3D，支持 WASD、鼠标视角和手柄右摇杆。 | 步速 2.2m/s，跑速 4.0m/s，视角高度 1.65m。 |
| 导览路径 | 设置 6 个预设点：大门、前院、主厅、书房、后院、鸟瞰。 | 按钮触发 Tween 平滑移动，相机过渡 1.2–1.8 秒。 |
| 光照 | DirectionalLight3D 负责太阳，WorldEnvironment 负责天空和环境雾。 | 提供清晨、午后、黄昏、夜景四套 preset。 |
| 水体 | 荷花池与后院叠水使用透明材质、法线扰动和轻微反射。 | 水面粗糙度 0.05–0.12，法线速度低于 0.03。 |
| 热点说明 | 在影壁、水池、青龙廊、白虎石、后院假山处放 Area3D 热点。 | 进入触发 UI 卡片，解释对应风水含义。 |

## 九、落地顺序

1. 完成 Blender 灰盒：先锁定 42m × 34m 基地、主楼 18m × 12m、前院 12m × 10m、后院 14m × 8m。
2. 建立 P0 资产：主楼、门楼、影壁、荷花池、假山、院墙、连廊。
3. 替换 P1 室内与侧院资产：大堂、书房茶室、餐厅、主卧、厨房、佛堂。
4. 导入 Godot：按 Exterior / Interior / Landscape 分组导入，先完成静态漫游，再加水体、热点和日夜切换。
5. 二次效果图：在模型确认后补充夜景、卧室、餐厅、厨房和佛堂视角。
